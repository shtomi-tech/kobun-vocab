# 歴史的仮名遣いを読む
![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

歴史的仮名遣いは、一文字ずつ機械的に置き換えません。語の位置と組み合わせを見て読みを直し、最後に単語全体と文の意味で照合します。順番を固定すると、見慣れない表記にも対応できます。

## 1　ハ行は語の位置を見る

:::board
ハ行の読み替え
語頭ではハ行音、語中・語尾ではワ行音になる例がある
:::

「あはれ」は「あわれ」、「かは」は「かわ」です。一方、「はな（花）」の「は」は語頭なので「はな」と読みます。同じ文字でも位置が根拠になります。

:::check check-kobun-01-yomi-01
question: 「あはれ」は「あわれ」と読むのに、「はな(花)」は「わな」とは読まない。この違いの理由として正しいものはどれか。
choice: A|「はな」の「は」は語頭にあり、読み替えの対象外だから
choice: B|「はな」は名詞で、「あはれ」は名詞ではないから
answer: A
explanation: ハ行をワ行音で読むのは、語中・語尾にある場合に限られる。「あはれ」の「は」は語中なので「わ」と読むが、「はな」の「は」は語頭なので読み替えない。読み替えるかどうかは、その仮名が語のどの位置にあるかだけで決まる。
:::

## 2　ゐ・ゑ・をなどを直す

:::board
特別な仮名
ゐ＝い　ゑ＝え　を＝お　ぢ＝じ　づ＝ず
くわ＝か　ぐわ＝が
:::

「ゐる」は「いる」、「こゑ」は「こえ」と読みます。「ぢ」は「じ」、「づ」は「ず」と読み、「はぢ」は「はじ」、「みづ」は「みず」です。「くわ」は「か」、「ぐわ」は「が」と読み、「くわじ」は「かじ」、「ぐわん」は「がん」です。「を」は助詞の表記にも現れるので、読んでいる語のどの部分かを見ます。仮名だけでなく、語全体を確認します。

:::check check-kobun-01-yomi-02
question: 「ゐ・ゑ・を」の読み方の組み合わせとして正しいものはどれか。
choice: B|い・え・お
choice: A|ゐ・ゑ・を
answer: B
explanation: ワ行の「ゐ」「ゑ」と、助詞以外の「を」は、それぞれ「い」「え」「お」と読む。「ゐる(居る)」は「いる」、「こゑ(声)」は「こえ」、「をとこ(男)」は「おとこ」。助詞の「を」は現代語でもそのまま「を」と書くので、混同しないこと。
:::

## 3　母音の連続を長音にする

:::board
置き換えのあとに音を整える
au系 → オーの音　eu系 → ヨーの音になる例がある
:::

「やうやう」は「ようよう」、「まうす」は「もうす」です。先に仮名を置き換え、その結果できた母音の連続を読み直します。順序を逆にすると、材料を混ぜやすくなります。

:::check check-kobun-01-yomi-03
question: 「やうやう」の現代仮名遣いの読みとして正しいものはどれか。
choice: A|ようよう
choice: B|やうやう
answer: A
explanation: 「au」の並びは長音「オー」になり、「やう」は「よう」と読む。したがって「やうやう」は「ようよう」。同じ規則で「まうす(申す)」は「もうす」となる。
:::

## 4　「けふ」は二段階で読む

:::board
読み替えの順番
けふ → けう → きょう
:::

「けふ」は、まず語尾の「ふ」を「う」に直して「けう」とし、そこから「ｅｕ」の読み替えで「きょう」にします。「てふ」も同じ順番で「ちょう」です。

:::check check-kobun-01-yomi-04
question: 「けふ」の現代仮名遣いの読みとして正しいものはどれか。
choice: B|きょう
choice: A|けう
answer: B
explanation: まず語尾のハ行「ふ」を「う」と読んで「けう」、次に「eu」の並びが長音「ヨー」になるため「きょう」と読む。2つの規則を順に当てはめる点が要点。同じ手順で「てふ(蝶)」は「ちょう」となる。
:::

## 5　四段階の手順を固定する

:::board
歴史的仮名遣いの読み方
位置を見る → 仮名を置き換える → 母音を整える → 単語と文で照合する
:::

意味から先に読みを作るのではなく、文字の形から順番に処理します。最後に単語全体と文の意味を確かめれば、途中で迷っても一つ前の段階へ戻れます。

:::check check-kobun-01-yomi-05
question: 歴史的仮名遣いを読むときの手順として、最も適切なものはどれか。
choice: A|1字ずつ置き換えてから、残った母音の連続を長音に直す
choice: B|先に母音の連続を長音に直してから、1字ずつ置き換える
answer: A
explanation: 「けふ」の例のように、まず字の置き換え(ふ→う)を行い、その結果できた母音の連続(eu)を長音に直す、という順で処理する。順序が逆だと、置き換え前の字を材料に長音を判断してしまい、誤読につながる。
:::

:::practice
次は、どの文字をどの順番で直したかを説明しながら、古文の語を読んでみます。
:::
