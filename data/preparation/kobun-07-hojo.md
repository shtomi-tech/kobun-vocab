# 補助動詞の訳し方

敬語の補助動詞は、前の動詞に敬意や丁寧さを加えます。まず本動詞か補助動詞かを分け、次に敬語の種類と敬意の方向を決め、最後に訳の型へ移します。

## 1　前の動詞とのつながりを見る

:::board
補助動詞の入口
前の動詞の下に付く → 前の動作へ敬意・丁寧さを加える
:::

「〜て給ふ」「〜奉る」のように前の動詞に続くなら、補助動詞の候補です。単語だけを辞書の意味で訳さず、前の動作を先に確認します。

:::check check-kobun-07-hojo-01
question: 「奉る」の働き・意味として適切なのは？ 例文:この由を宮に知らせむとて、文を書き奉る。
choice: A|文を書き申し上げる
choice: B|文をお書きになる
answer: A
explanation: 謙譲の補助動詞なので「〜し申し上げる」の型。訳は「手紙を書き申し上げる」。
:::

## 2　敬語の種類を訳へ移す

:::board
訳の型
謙譲＝お〜申し上げる　尊敬＝〜なさる・お〜になる
丁寧＝〜ます・〜ございます
:::

謙譲は動作の相手、尊敬は動作主、丁寧は聞き手や読み手への配慮を訳に反映します。「〜される」だけで済ませず、誰を高める働きかを残します。

:::check check-kobun-07-hojo-02
question: 「候ふ」の働き・意味として適切なのは？ 例文:「都のさま、いと変はりて見え候ふ」と言ふ。
choice: B|見えます
choice: A|お見えになる
answer: B
explanation: 丁寧の補助動詞なので「〜です・〜ます」の型。訳は「都の様子は、たいそう変わって見えます」。
:::

## 3　敬意の方向と訳を照合する

:::board
最後の順番
前の動作 → 敬語の種類 → 動作主・客体 → 訳の型
:::

補助動詞の形だけでは、人物関係まで決まりません。会話か地の文かも確認し、訳の敬意の向きが本文の人物関係と矛盾しないかを確かめます。

:::check check-kobun-07-hojo-03
question: 「給ふ」の働き・意味として適切なのは？ 例文:帝、みづから歌を書き給ふ。
choice: A|お書きになる
choice: B|書き申し上げる
answer: A
explanation: 尊敬の補助動詞なので「お〜になる」の型。訳は「帝は、自らお歌をお書きになる」。
:::

:::practice
次は、補助動詞の種類を確定し、前の動作と敬意の方向を含む訳を選びます。
:::
