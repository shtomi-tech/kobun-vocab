# ぬ・ねの識別

「ぬ・ね」は、打消の「ず」と完了の「ぬ」が同じ形で現れます。直前の活用形を見たあと、必要なら「ぬ・ね」自身の活用形で裏づけます。

## 1　上の形で打消か完了かを分ける

:::board
最初の分岐
未然形＋ず → 打消　連用形＋ぬ → 完了・強意
:::

「咲かぬ」は「咲か」が未然形なので「咲かない」、「咲きぬ」は連用形なので「咲いた・咲いてしまった」の候補です。

:::check check-kobun-06-nune-01
question: 「ぬ」の働き・意味として適切なのは？ 例文:独りやぬらん
choice: A|ナ行下二段活用動詞「寝」の一部
choice: B|打消の助動詞「ず」の連体形
answer: A
explanation: 「ぬ」は直前が何形かを先に確かめる。ここは直前に活用語がなく、「ぬ」自体がナ行下二段活用の動詞「寝」の終止形。下に終止形接続の推量「らむ」が続くことも、終止形である裏付けになる。「独りで寝るのだろうか」と訳す。
:::

## 2　下の位置で裏づける

:::board
「ぬ・ね」自身の形
ずの連体形＝ぬ・已然形＝ね　ぬの終止形＝ぬ・命令形＝ね
:::

名詞の前なら打消「ず」の連体形、文末や命令の位置なら完了「ぬ」の形も考えます。完了の下に推量が続く場合は、強意の訳を候補にします。

:::check check-kobun-06-nune-02
question: 「ね」の働き・意味として適切なのは？ 例文:「今は帰りね」と言ひければ
choice: B|完了の助動詞「ぬ」の命令形
choice: A|打消の助動詞「ず」の已然形
answer: B
explanation: 連用形接続で、文末の命令形「ね」なので完了の助動詞「ぬ」。「今は帰ってしまえ」と訳す。
:::

## 3　訳を本文へ戻す

:::board
最後の確認
接続 → 自身の活用形 → 下に続く語 → 打消・完了・強意
:::

「ぬ＝ない」「ぬ＝完了」と暗記で固定せず、上の語と下の語を一緒に読みます。二つの形から同じ候補が残ったときだけ、文脈で訳を決めます。

:::check check-kobun-06-nune-03
question: 「ぬ」の働き・意味として適切なのは？ 例文:商人心得ぬことと思ひながら
choice: A|打消の助動詞「ず」の連体形
choice: B|完了の助動詞「ぬ」の終止形
answer: A
explanation: 「ぬ」は直前の活用形で決める。「心得」は下二段活用「心得(こころう)」の未然形で、未然形に付く「ぬ」は打消の助動詞「ず」の連体形。下に体言「こと」が続くことも、連体形である裏付けになる。「商人が納得できないことと思いながら」と訳す。
:::
