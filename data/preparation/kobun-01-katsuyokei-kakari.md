# 活用形と係り結びを読む
![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

活用形を決めるときは、語の見た目だけでなく、下に何が続くかを先に見ます。未然・連用・終止・連体・已然・命令の六つを地図にして、助動詞や助詞の接続を読み取ります。

## 1　六つの活用形を並べる

:::board
活用形の順番
未然 → 連用 → 終止 → 連体 → 已然 → 命令
:::

古文では、現代語の「仮定形」に近い位置を已然形と呼びます。名前そのものに意味を固定せず、活用表の位置と後続語を確認します。

:::check check-kobun-01-katsuyokei-kakari-01
question: 古文の活用形を順に並べたものとして正しいものはどれか。
choice: A|未然形・連用形・終止形・連体形・已然形・命令形
choice: B|未然形・連用形・終止形・連体形・仮定形・命令形
answer: A
explanation: 古文の活用形は、未然形・連用形・終止形・連体形・已然形・命令形の6つで、活用表もこの順に並ぶ。現代語文法の「仮定形」にあたる位置に、古文では「已然形」が入る点が最大の違い。
:::

## 2　未然形と連用形は下で決める

:::board
後ろの語から逆算する
「行かず」＝未然形＋ず　「咲きて」＝連用形＋て
:::

「ず」は未然形、「て」は連用形に付くため、直前の「行か」「咲き」の形を決められます。活用形が分かれば、後ろに続く語の候補も狭まります。

:::check check-kobun-01-katsuyokei-kakari-02
question: 「行かず」の「行か」は何形か。
choice: B|未然形
choice: A|連用形
answer: B
explanation: 活用形は、下に何が続くかで決める。打消の助動詞「ず」は未然形に接続するので、「行か」は未然形。未然形は「まだそうなっていない」の意で、「ず」「む」「ば(仮定)」「る・らる」「す・さす」などが下に付く。
:::

## 3　終止形と連体形を区別する

:::board
言い切りか、名詞を修飾するか
終止形＝文をいったん終える　連体形＝体言を詳しくする
:::

「行く。」の「行く」は言い切りの終止形、「行く人」の「行く」は連体形です。四段活用では形が同じことがあるので、語尾でなく後ろの働きを見ます。

:::check check-kobun-01-katsuyokei-kakari-03
question: 「行く人」の「行く」は何形か。
choice: A|連体形
choice: B|終止形
answer: A
explanation: 下に体言(名詞)「人」が続いているので連体形。四段活用では終止形と連体形が同じ形になるため、形だけでは決まらず、下に何が続くかで判断する必要がある。この「形が同じで区別できない」という事情が、後の識別問題(「なり」「なむ」など)でそのまま効いてくる。
:::

## 4　係助詞を見たら文末へ進む

:::board
係り結び
ぞ・なむ・や・か → 連体形　こそ → 已然形
:::

「花ぞ咲く」の「咲く」は、見た目は終止形と同じでも、ぞを受ける連体形です。「人こそ来れ」では、こそを受けて「来れ」が已然形になります。まず形を決め、そのあと「やは・かは」が応答を求める疑問か、話し手の強い主張を含む反語かを文脈で判断します。

:::check check-kobun-01-katsuyokei-kakari-04
question: 「花ぞ咲く」のように文中に係助詞「ぞ」があるとき、文末はどの活用形で結ぶか。
choice: B|連体形
choice: A|終止形
answer: B
explanation: 係助詞「ぞ・なむ・や・か」があると、文末は連体形で結ぶ。「こそ」だけは已然形で結ぶ。文末が言い切りの位置にあっても連体形になるのはこの係り結びによるもので、活用形を判定するときは文中の係助詞の有無を先に確認する。
:::

## 5　「ば」の前の形を比べる

:::board
同じ「ば」でも上の形が違う
已然形＋ば → 確定条件「〜ので・〜と」
未然形＋ば → 仮定条件「もし〜ならば」
:::

「雨降れば」の「降れ」は已然形、「雨降らば」の「降ら」は未然形です。まず「ば」の上の形を確定し、そのあとで条件の意味を文全体に合わせます。

:::check check-kobun-01-katsuyokei-kakari-05
question: 「雨降れば」の「降れ」は何形か。
choice: A|已然形
choice: B|未然形
answer: A
explanation: 四段活用「降る」の未然形は「降ら」、已然形は「降れ」。ここは「降れ」なので已然形で、已然形+「ば」は確定条件(〜ので、〜と)を表す。同じ「ば」でも未然形+「ば」なら仮定条件(もし〜ならば)になるため、上の活用形を必ず確認する。
:::

## 6　終止形接続の語が続くとき

:::board
終止形接続の助動詞を見たら
まず終止形。ただしラ変型の後ろは連体形になることがある
:::

「咲くらむ」「読むべし」のように終止形接続の助動詞が続く場合は、直前の形を確かめます。ラ変型「あり・をり・はべり」の後ろでは連体形になる例外があるため、語の種類まで確認します。

:::check check-kobun-01-katsuyokei-kakari-06
question: 係助詞「こそ」があるとき、文末はどの活用形で結ぶか。
choice: B|已然形
choice: A|連体形
answer: B
explanation: 「こそ」の結びは已然形。「ぞ・なむ・や・か」の連体形結びと対にして覚える。さらに「こそ〜已然形、」の形で文が切れずに後ろへ続く場合は、強意ではなく逆接(〜けれども)を表す特殊な構文になる。
:::

## 7　こその結びと疑問・反語

:::board
係助詞の最後の確認
こそ → 已然形　や・か＋疑問語 → 反語の候補
:::

「こそ」は文末を已然形で結びます。「やは」「かは」に疑問語が呼応するときは、単なる質問でなく反語になることがあるため、文全体の答えの有無も読みます。

:::check check-kobun-01-katsuyokei-kakari-07
question: 「やは」「かは」を含む文を読むとき、疑問か反語かを判断する手がかりとして最も適切なものはどれか。
choice: A|主張が読み取れれば反語、なければ疑問とする
choice: B|「やは・かは」の直後に体言があれば必ず疑問と判断する
answer: A
explanation: 「やは・かは」は反語になりやすいが、形だけで自動的に決まるわけではない。応答を求める文脈なら疑問、話し手の強い主張(〜だろうか、いや〜ない)が読み取れれば反語と判断する。
:::
