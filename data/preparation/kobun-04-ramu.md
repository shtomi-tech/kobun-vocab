# らむの識別

「らむ」は終止形に接続し、ラ変型の後ろでは連体形に付くことがあります。現在の事柄を対象に、事実・原因・伝聞・婉曲を分けます。

## 1　現在の事実か原因かを分ける

:::board
推量の向き
事実そのもの →「今ごろ〜だろう」
原因・理由 →「なぜ〜のだろう」
:::

目の前にない現在の状態や出来事を考えていれば現在推量、見えている事実の理由を考えていれば現在原因推量です。疑問詞や前後の問いかけを手がかりにします。

:::check check-kobun-04-ramu-01
question: 「らむ」の働き・意味として適切なのは？ 例文:わが宿に咲ける藤波立ち返り過ぎがてにのみ人の見るらむ
choice: A|現在原因推量
choice: B|現在推量
answer: A
explanation: 現在の事実である「人が見る」ことの原因を推量しているので、現在原因推量。「人が、立ち返って通り過ぎることができないので見るのだろう」と訳す。
:::

## 2　体言を修飾する形を読む

:::board
連体修飾と省略
体言を修飾 → 伝聞・婉曲を候補にする
:::

「らむ」が名詞を修飾したり、「こと・話」が省略されたりしていれば、現在の伝聞・婉曲も考えます。「〜とかいう」「〜という話だ」「〜ような」と訳を比べます。

:::check check-kobun-04-ramu-02
question: 「らむ」の働き・意味として適切なのは？ 例文:旅人より、この里に宝の出づらむと聞きたり。
choice: B|現在の伝聞
choice: A|現在推量
answer: B
explanation: 情報源を表す「旅人より聞きたり」と結び付き、「宝が出るとかいう」と伝え聞いた内容を表すので、現在の伝聞。
:::

## 3　接続と訳を最後に照合する

:::board
確認の順番
終止形接続 → 現在の対象 → 事実・原因・伝聞・婉曲
:::

後ろに体言があるだけで婉曲と決めません。直前の形を確かめ、らむが何について推量しているかを本文から説明できる訳を選びます。

:::check check-kobun-04-ramu-03
question: 「らむ」の働き・意味として適切なのは？ 例文:「何事思ひ給ふぞ。思すらむこと、何事ぞ」
choice: A|現在の婉曲
choice: B|現在推量
answer: A
explanation: 体言「こと」を修飾し、「お思いになるようなこと」と断定を避けて述べているので、現在の婉曲。
:::

:::practice
次は、現在という時間を固定し、らむの推量の対象と訳を対応させます。
:::
