# 古典文法ロードマップ v2

## 方針

対象は、知的好奇心が強い12歳の学習者。暗記表を先に渡すのではなく、本文の中で「どの語が、何をしているか」を追える順に並べる。

- 文の骨組みを先に置く
- 用言の形を使えるようにしてから、助動詞へ進む
- 助動詞は接続グループごとに、形（活用表）と意味（基本意味・識別）を1つの必修にまとめる
- 助詞は基本機能と文末・呼応を分ける
- 同形語は、接続を知った後に扱う
- 敬語は単独の語彙ではなく、人物関係と補助動詞まで含めて読む
- 各段階は一度きりの暗記で終えず、最後の混合確認で再登場させる
- 各段階の入口に短い予習資料を置き、資料で見通しを作ってから問題で確かめる

## 必修順

| 段階 | 内容 | 前提とのつながり |
|---|---|---|
| 1 | 文の骨組み | 音・文節・品詞から、述語・修飾語・対象・省略主語へ進む |
| 2 | 用言の活用 | 種類を決める→活用表を読む→活用表を埋める→語幹・音便→訳し分けの順に扱う |
| 3 | 未然形接続の助動詞 | 11語を活用表→基本意味→識別まで一続きに扱う |
| 4 | 連用形接続の助動詞 | き・けり・つ・ぬ・たり・けむ・たし の順に、活用表と意味・識別を通して固める |
| 5 | 終止形接続の助動詞 | 6語を、推量の種類ごとに読み分ける。ラ変型への接続もここで扱う |
| 6 | 体言・連体形接続の助動詞 | 3語（なり・たり・ごとし）を押さえ、助動詞の意味を全体で仕上げる |
| 7 | 助詞・呼応・文末 | 助詞の地図から、係り結び・禁止・願望・念押しへ広げる |
| 8 | 同形語 | 「ぬ・ね」「る・れ」「なり」「なむ」「に」を接続と文中の働きで分ける |
| 9 | 敬語・補助動詞 | 敬語の種類、補助動詞、敬意の方向を人物関係に接続する |
| 10 | 文法混合確認 | 1〜9の4択を混ぜ、単元の境界を越えて判断する |

## 追加した範囲

- `文の成分と省略`: 述語、連体修飾語、動作の対象、接続助詞からの主語の仮置き
- `語幹・音便`: イ音便・促音便、音便の復元手順、形容詞の語幹用法
- `ず・まほしの基本意味`: 助動詞表にあるだけで終わっていた2語を、意味の必修問題へ追加
- `助詞の地図` / `呼応・文末`: 既存の助詞問題を役割別に分割し、基本から特殊構文へ進める
- `接続別の助動詞4必修`: 旧「必修3 助動詞の形」「必修4 助動詞の意味」を、未然形／連用形／終止形／体言・連体形の4必修へ再編した。28語の表を先に全部埋める構成では、形の暗記と意味判断の間隔が開きすぎるため、同じ接続の語で「活用表 → 基本意味 → 識別手順」を完結させる。接続は形と意味をつなぐ軸なので、必修1の「接続という考え方」に旧「接続で識別する」5問を統合し、考え方→接続の一覧→同形語の切り分けを14問1タスクにまとめた。助動詞の必修はその土台の上に置く
- `活用の種類の見分け方` / `用言の活用表を読む` / `語幹の用法と訳し分け`: Chapter 2の25問を役割別に3分割し、活用表の行埋めの前に「種類を決める」「表の並びを選択肢で照合する」を置いた。行埋めは表を自力で再生する課題なので、再生の前に見分け方と各活用型の並びを確かめる
- `活用の種類の見分け方の実践化`: 上記の3分割時点では「見分け方」グループが9種類の全体像・変格活用の組み合わせ・上一段の所属語・「ず」で段を見る手順の説明・形容詞のク活用シク活用の5問の寄せ集めで、実際の動詞に「ず」を適用して四段・上二段・下二段を判別する練習が無かった。動詞と無関係な形容詞の問題（旧c2-023）をグループと必修ルートから外し、書く・知る・待つ（四段）／過ぐ・落つ・恥づ（上二段）／出づ（下二段）に「ず」を適用する練習と、活用の種類が他と異なる語を選ぶ総合判別問題の計8問（c2-031〜c2-038）を追加して、グループを動詞の四段・上二段・下二段判別に特化させた（2026-08-03）
- `未然形接続タスクの語順`: 必修3のタスク順を活用表（g1）と同じ語順（る・らる・す・さす・しむ・ず・じ・む・むず・まし・まほし）に揃えた。基本意味の「ず・まほし」は2問1タスクだと語順から外れるため1問ずつに分割。「じ・む・むず」は意味の決め方が同じ（人称で場合分けし、じはむの打消側）なので識別は1タスクのままだが、`data/shikibetsu.json` の sb-mu グループの出題順を「じ→む→むず」に並べ替え、タスク内の実践順も語順に合わせた
- `連用形接続タスクの語順とりの移動`: 必修4のタスク順を「き・けり・つ・ぬ・たり（完了）・けむ・たし」に揃えた。「たり・りの識別」（完了・存続の意味と見分け方がたりと共通）は旧必修6（体言・連体形接続）にあったが、たりのすぐ後ろで学べるよう必修4へ移動。連動して `katsuyo.json` の活用表グループも、り（サ変未然形・四段已然形接続）をg4からg2へ移し、タスク名を「連用形接続7語＋りの活用表」「体言・連体形接続3語の活用表」に変更。基本意味は語ペアごとの識別直後に置けるよう、き・けり／つ・ぬ／たり・り／たしの4タスクに分割した（けむには基本意味の単問が無い）
- `基本意味と識別の統合`（2026-08-03）: き・けり／つ・ぬ／たり・り／らむの4組は、`kiso.json` の基本意味設問（抽象・文脈無しの1問）と `shikibetsu.json` の識別タスク（手順文＋文脈付き実践問題）が両方存在していた。内容を比較すると、この4組の基本意味設問が問う内容は、対応する識別タスクの予習資料（`data/preparation/kobun-04-keri.md`・`kobun-04-tsunu.md`・`kobun-04-tariri.md`・`kobun-04-ramu.md`）にほぼ一言一句の水準で既に書かれていたため、`c5-001・c5-002・c5-003・c5-006・c5-007` の5問を削除し、必修4・5のロードマップタスクからも該当項目を外した。ず・まほし・たし・らしは対応する識別タスクが無いため基本意味のまま残している。文法混合確認（30問）は識別の実践問題を出題形式の違いから元々除外しているため、この4組の意味区別は混合確認での再登場がなくなり、識別タスク内での練習のみになる

本文の主語補充は、接続助詞だけで断定しない。まず仮置きし、敬語と文脈で照合する。古文は、こちらの都合よく全員が整列してくれるわけではない。

## 予習資料

必修1〜9には、12歳の学習者が問題の前に読める短い資料を用意する。資料は `data/preparation/` にMarkdownで置き、ロードマップの「次にやること」または各タスクの「予習」から開く。資料の末尾から同じタスクの問題へ進み、各タスク行の問題ボタンからは資料を飛ばして直接演習もできる。

## 研究上の根拠

学校文法の範囲は学習指導要領を基準にし、教材の一般的な配列と、想起練習・分散学習の知見を組み合わせた。単元順そのものを唯一の正解とはせず、本文読解で再利用できる依存関係を優先した。
